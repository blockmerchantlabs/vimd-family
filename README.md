# visualidentity.md: IMD, as it is today

Entry for VisualIdentity.md Edition 2 (IMD launch 1671, contract `0xECb21b6c3Bf69e09A2E34DB1f0B25c34586FF1c9`).

This package records IMD's existing look (imd.fun, the IMD coin, IMD Radar and SIMD) so that a page built from `visualidentity.md` at its defaults comes out as the IMD site with the IMD mark.

- Guide: `visualidentity.md`
- Tokens: `tokens.css`, `colors.json`, `identity.json`
- Assets: `assets/` (IMD's own marks, taken from imd.fun and IMD's coin)
- Example page: `example/index.html`
- File checksums: `MANIFEST.txt`

The entry's package link points at the zip attached to release `v1`; its sha256 is stored on chain with the entry.

All marks belong to IMD.
