# VIMD Family

A small, ready-made visual identity for when a project, or the AI building it, has no design preference yet and needs a sensible place to start. Use it as is, change any part of it, or use none of it.

Four themes (slate by default, stone, white, black), one font, a few layout rules, and a neutral logo to start from. Made in the IMD community as an entry for VisualIdentity.md Edition 2 (IMD launch 1671, `0xECb21b6c3Bf69e09A2E34DB1f0B25c34586FF1c9`). Free to use.

**One line in a job brings in the whole package:**

> Use the visual identity package at https://raw.githubusercontent.com/blockmerchantlabs/vimd-family/v3/visualidentity.md for every colour, font, layout rule and the logo.

- Guide: `visualidentity.md` (self-contained; every file it names has a link pinned to tag `v3`)
- Tokens: `tokens.css`, `tokens.json` (W3C Design Tokens format), `colors.json`, `identity.json`
- Logo: `assets/family-base-pepe.png`, with an example variant and IMD's own marks for reference
- Showcase: `example/index.html`, live at https://blockmerchantlabs.github.io/vimd-family/
- Fill-in template: `template/visualidentity-template.md`
- Checksums: `MANIFEST.txt`

The colours, tokens, layout rules and text are free to use for any purpose, no credit needed. IMD's marks belong to IMD and their artists; Pepe the Frog is Matt Furie's character.
